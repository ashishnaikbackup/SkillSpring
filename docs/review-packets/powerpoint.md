## Course introduction

Build presentations that explain ideas clearly, tell a coherent story and work reliably in classrooms, interviews and business meetings.

## Lessons

### 1. Interface, slides & slide layouts

**Concept.** A presentation is a sequence of visual pages supporting a message. Learn Normal view, Slide Sorter, Notes, layouts, placeholders, themes and presenter view.

**Example**

```
Create a 5-slide deck using built-in layouts. Add a title, agenda, problem, evidence and conclusion. Save as PPTX.
```

**Task.** Deliverable: a short introduction deck with consistent layouts.

**Quiz.** What is the purpose of a slide layout?
- Correct: It provides a consistent arrangement of content placeholders
- Wrong: It writes the speech automatically
- Wrong: It compresses all images

### 2. Storytelling & slide structure

**Concept.** Start with the audience and the decision or understanding you want. Build a narrative: context, problem, evidence, insight, recommendation and next step. One main idea per slide improves clarity.

**Example**

```
Turn a long paragraph into a headline plus three supporting points. Order slides so each answers the question raised by the previous one.
```

**Task.** Create a 6-slide story explaining a problem and proposing a solution.

**Quiz.** What should a strong slide communicate?
- Correct: One clear main idea supported by relevant evidence
- Wrong: Every detail from the report
- Wrong: Several unrelated messages

**Findings:** _none yet_

### 3. Typography, colour & visual hierarchy

**Concept.** Use readable type, consistent sizes, contrast, alignment, whitespace and a limited colour palette. Use emphasis to guide attention. Avoid tiny text and decorative clutter.

**Example**

```
Create a title, section heading, body and footnote hierarchy. Align objects and use guides. Check contrast and readability from a distance.
```

**Task.** Redesign a crowded slide into a clean visual with a clear focal point.

**Quiz.** Why limit fonts and colours?
- Correct: To improve consistency and reduce visual noise
- Wrong: To make every slide identical
- Wrong: To hide missing information

**Findings:** _none yet_

### 4. Charts, diagrams & visual evidence

**Concept.** Choose a chart based on the question: line for trends, bar for comparisons, scatter for relationships. Label units, show sources and avoid misleading axes. Diagrams explain processes and relationships.

**Example**

```
Convert a small sample dataset into a labelled bar chart. Add a source note and a one-sentence takeaway. Build a simple process diagram.
```

**Task.** Create a data slide with a chart and a takeaway headline.

**Quiz.** What is essential on a chart used for a decision?
- Correct: Clear labels, units, source and honest scale
- Wrong: 3D effects
- Wrong: Unlabelled axes

**Findings:** _none yet_

### 5. Images, media & animation

**Concept.** Use licensed, relevant visuals. Crop consistently and provide alt text where appropriate. Animation should reveal sequence or explain change, not distract. Rehearse media playback and test on the presentation device.

**Example**

```
Add one image with attribution, one simple process animation and speaker notes. Test playback and use animation sparingly.
```

**Task.** Create a 3-step process slide with restrained transitions and notes.

**Quiz.** When is animation useful?
- Correct: When it clarifies sequence or directs attention
- Wrong: On every object by default
- Wrong: To replace a clear explanation

**Findings:** _none yet_

### 6. Master slides, delivery & accessibility

**Concept.** Slide Master controls repeated elements, themes and layouts. Use meaningful reading order, accessible contrast, captions and notes. Rehearse timings, use presenter view and export a PDF backup.

**Example**

```
Create a theme with master title/content layouts, consistent footer and accessible contrast. Rehearse a 3-minute talk and export PDF.
```

**Task.** Prepare a reusable presentation template and a tested delivery copy.

**Quiz.** What does Slide Master help manage?
- Correct: Consistent global design and layouts
- Wrong: Audience registration
- Wrong: Internet connectivity

**Findings:** _none yet_

### 7. Professional presentation capstone

**Concept.** A professional deck supports a talk: opening, context, evidence, analysis, recommendation, risks and call to action. Keep backup files and prepare to answer questions with evidence.

**Example**

```
Build a 10-slide project or business proposal deck. Add speaker notes, sources, a clear conclusion and appendix for details. Rehearse and time it.
```

**Task.** Capstone: deliver PPTX, PDF and a 3-minute spoken presentation with Q&A preparation.

**Quiz.** What should you do before presenting on another computer?
- Correct: Test fonts, media, links and backup PDF on the actual setup
- Wrong: Assume everything will look identical
- Wrong: Remove all speaker notes
