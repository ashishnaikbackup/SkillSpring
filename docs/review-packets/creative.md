## Course introduction

Learn the fundamentals of visual communication, design systems, content production, storytelling and responsible publishing. Use original or properly licensed assets.

## Lessons

### 1. Visual communication and design principles

**Concept.** Design helps people notice, understand and act. Contrast creates hierarchy; alignment creates order; proximity groups related information; repetition builds consistency; whitespace reduces clutter. Design for the audience and task.

**Example**

```
A poster with one clear headline, supporting detail and one action is easier to scan than a page where every element has equal size and colour.
```

**Explanation / note.** Hierarchy guides attention and supports comprehension.

**Task.** Redesign a cluttered fictional event announcement using hierarchy, alignment, spacing and a clear call to action. Explain each choice.

**Quiz.** What does visual hierarchy help a viewer do?
- Correct: Understand the order and importance of information
- Wrong: Make every element equally prominent
- Wrong: Hide the main message

### 2. Colour, typography and layout systems

**Concept.** Colour has functional and cultural context; do not use colour alone to communicate status. Typography needs readable size, line length and contrast. A layout system uses spacing, grids and reusable components.

**Example**

```
A status dashboard can pair a colour with text such as 'Delayed' and an icon, so the meaning is not lost for colour-blind users.
```

**Explanation / note.** Text labels and shapes provide redundant cues.

**Task.** Create a mini style guide with type scale, spacing tokens, colour roles and examples of accessible status labels.

**Quiz.** Why should colour not be the only way to communicate meaning?
- Correct: Some users may not distinguish the colours or may use non-visual access
- Wrong: It makes files larger
- Wrong: It prevents printing

### 3. Branding and visual identity

**Concept.** A brand identity is a consistent system of name, voice, visual marks, colour and usage rules. A logo is one asset, not the whole brand. Research audience, competitors and context before designing.

**Example**

```
A simple identity system might define a primary logo, clear-space rule, minimum size, two typefaces and colour values with contrast guidance.
```

**Explanation / note.** Guidelines preserve coherence; they do not guarantee market outcomes.

**Task.** Create a one-page identity board for a fictional student service. Include audience, positioning, logo concept, palette, typography and usage rules.

**Quiz.** What should a brand guideline help others do?
- Correct: Apply the identity consistently across different materials
- Wrong: Choose a random new logo each day
- Wrong: Guarantee business success

### 4. Image, audio and video production

**Concept.** Production has pre-production, capture, editing and export stages. Plan a shot list or recording outline. Check resolution, aspect ratio, audio levels, captions and output format. Keep source files and versioned exports.

**Example**

```
A 30-second explainer can use a hook, three visual steps and a closing action. Captions help viewers who cannot hear the audio.
```

**Explanation / note.** Planning reduces avoidable reshoots and editing changes.

**Task.** Storyboard a short tutorial with six shots. Add a narration script, caption plan and export settings for mobile viewing.

**Quiz.** What belongs in pre-production?
- Correct: Brief, audience, script/storyboard and shot plan
- Wrong: Only the final export
- Wrong: Deleting source files

### 5. Storytelling and content strategy

**Concept.** A useful story has audience, purpose, context, evidence and a clear takeaway. A content plan defines format, cadence, source verification and feedback. Do not invent facts, misrepresent quotes or use copyrighted material without permission.

**Example**

```
A factual explainer separates what is confirmed, what is alleged and what remains unknown, then links to primary sources.
```

**Explanation / note.** Traceable sources support accuracy and accountability.

**Task.** Create a 60-second educational content outline with a hook, verified facts, source list, caveat and clear ending.

**Quiz.** Why keep a source list for factual content?
- Correct: So claims can be checked and corrected
- Wrong: To make the video longer
- Wrong: To avoid explaining uncertainty

### 6. Accessible and inclusive creative work

**Concept.** Creative work should be usable by as many people as possible. Check colour contrast between text and background, avoid using colour alone to carry meaning, and use readable type sizes. Add alt text to meaningful images, captions or transcripts to video and audio, and keep a logical reading order in documents and slides. Plain language and clear structure help everyone. Test with real users where possible, and include accessibility notes in your portfolio because employers value it.

**Example**

```
Accessibility checklist for a poster or slide
  [ ] Text contrast is clear in a greyscale preview
  [ ] Key information is not shown by colour alone
  [ ] Text is large enough to read from the expected distance
  [ ] Images have meaningful alt text in the digital version
  [ ] Video has captions; audio has a transcript
  [ ] Reading order follows the visual order
```

**Explanation / note.** Captions improve access and also help in noisy places or when sound is off.

**Task.** Take one of your own designs and audit it with the checklist. Fix three problems and record before and after screenshots with one sentence explaining each change.

**Quiz.** Why add captions to a video?
- Correct: They help people who are deaf or hard of hearing and anyone watching without sound
- Wrong: They make the video file smaller
- Wrong: They replace the need to record audio

### 7. Portfolio, licensing and professional delivery

**Concept.** A creative portfolio shows the brief, role, process, iterations, final work and reflection. Respect copyright, licences, releases, privacy and platform rules. Export accessible formats and retain editable source files.

**Example**

```
A case study explains the original problem, constraints, sketches, feedback, final result and what changed. It does not claim team work as an individual contribution.
```

**Explanation / note.** Honest attribution helps reviewers understand your actual contribution.

**Task.** Package three original practice pieces with project briefs, process notes, asset licences, captions/alt text and a reflection.

**Quiz.** What should you disclose when showing collaborative work?
- Correct: Your own role and the contributions of others
- Wrong: Claim all team work as yours
- Wrong: Hide the use of licensed assets
