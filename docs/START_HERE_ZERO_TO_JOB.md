# SkillSpring — Start Here: Zero to Job-Ready Skills

This guide is the recommended route for a learner starting with no programming or computer-science background. Do not skip foundations. Move forward when you can explain and use an idea without copying.

## Explore the full curriculum and graded practice

Use the [12-school curriculum map](../curriculum-map.html) to understand all course families and the eight-stage progression across programming, design, AI/data, electronics/VLSI, Office, finance, business, IT, career, creative media, productivity and mathematics/science. For hands-on JavaScript and SQL, use the [graded practice studio](../advanced-practice.html), which includes eight checked challenges per track. These supplement—not replace—the full courses below.

## The learning rule

For every concept:
1. Read the explanation and glossary.
2. Explain it in your own words.
3. Trace the worked example by hand.
4. Solve the guided exercise without looking at the solution.
5. Change the example and predict the result.
6. Complete a small independent problem.
7. Record mistakes and revisit them after a day and a week.

Watching a lesson is exposure, not mastery. A completed lesson should mean you produced evidence: code, a solved problem, a diagram, a report, a project or an explanation.

## Stage 0 — Digital and computer basics

Learn hardware, software, operating systems, applications, browsers, files/folders, paths, downloads, archives, backups, safe installation, terminal basics, privacy, passwords, phishing and safe API-key handling.

Evidence: organise a project folder, create a text file, open a terminal and explain the difference between a file, folder, application and operating system.

## Stage 1 — Programming logic before syntax

Open the [Programming Logic: Absolute Zero course](../essential-course.html?course=logic).

Learn input/process/output, decomposition, algorithms, pseudocode, flowcharts, variables, data types, operators, conditions, loops, functions, collections, debugging and testing.

Practice in this order: add two numbers; convert Celsius to Fahrenheit; check even/odd; find the largest of two and three numbers; calculate grades; print multiplication tables; sum 1 to N; count/reverse digits; check palindrome and prime; build a menu-driven calculator.

Do not move on until you can write the algorithm and trace it manually.

## Stage 2 — Choose one first language: Python

Python is recommended as a first language because its syntax is relatively readable. Learn printing, input, comments, indentation, variables, numbers, strings, booleans, type conversion, operators, conditions, loops, functions, parameters, return values, scope, lists, tuples, sets, dictionaries, strings, files, exceptions, modules, classes, testing, debugging, virtual environments and packages.

Open the Python course and use the Python playground. Type examples yourself; do not only copy and paste.

## Stage 3 — Daily problem-solving habit

For each problem: restate it; write inputs, outputs and constraints; make a small example by hand; write pseudocode; implement a brute-force solution; test normal, boundary and invalid cases; improve only when you can explain why; state time and space complexity when ready.

Suggested weekly rhythm: five days learning/practice, one day project work and one day revision/rest. A sustainable 60–90 minutes daily is better than occasional all-night sessions.

## Stage 4 — Git and software workflow

Complete the [Git & GitHub course](../essential-course.html?course=git). Learn repositories, working trees, staging, commits, branches, merges, remotes, pull requests, conflicts, README files, ignore rules, issue tracking and safe secret handling.

Evidence: publish a small project with setup instructions, screenshots, test cases, known limitations and a clean commit history.

## Stage 5 — Data Structures & Algorithms

Open the [DSA course](../essential-course.html?course=dsa).

Follow the dependency order: complexity and Big-O; arrays and strings; hash maps and sets; linked lists; stacks and queues; recursion and backtracking; searching and sorting; trees, BSTs and heaps; graphs, BFS and DFS; greedy methods and dynamic programming; two pointers, sliding window and prefix sums; interview communication and complexity trade-offs.

Target understanding rather than a magic number of solved questions. Keep a mistake notebook and revisit problems without looking at old code.

## Stage 6 — Build breadth around your chosen role

- Junior software/web role: HTML/CSS, JavaScript, HTTP, APIs, SQL, accessibility, testing and deployment.
- Data/business analyst: Excel, SQL, statistics, Power BI, data cleaning, visualisation and communication.
- IT/network role: computer fundamentals, operating systems, Linux, networking, troubleshooting, security and documentation.
- Electronics/VLSI/embedded: digital logic, C, microcontrollers, Verilog/SystemVerilog, simulation, verification and technical documentation.
- Office/operations: Word, Excel, PowerPoint, Outlook/Teams, reporting, databases and automation.

## Stage 7 — AI-assisted and vibe coding

Open the [AI-assisted coding course](../essential-course.html?course=vibecoding).

Use AI to accelerate learning and development: write requirements and acceptance criteria before prompting; ask for a plan before large changes; work in small diffs; inspect every change; ask for explanations and verify them; debug with reproducible errors; write and independently verify tests; never share secrets or private information; keep Git checkpoints; and never submit work you cannot explain and maintain.

## Stage 8 — Portfolio and job preparation

Aim for 3–5 meaningful projects rather than many unfinished clones. Each project should have a clear problem, requirements, design decisions, working demo or reproducible setup, readable code, tests, documentation, screenshots, known limitations and an explanation of your contribution.

Prepare a truthful role-specific CV, portfolio case studies, fundamentals questions, practical coding questions, behavioural examples using STAR, mock interviews and a role-specific skills gap plan.

## Important

No course, AI assistant or project can guarantee a job. Hiring depends on role fit, demonstrated ability, communication, market conditions and continued practice. SkillSpring should help learners build evidence and confidence, not promise employment. Course completion does not equal professional mastery; test yourself on unfamiliar problems and real tasks.
