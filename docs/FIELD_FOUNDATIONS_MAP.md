# Field-specific fundamentals map

SkillSpring must not assume that a learner already knows the prerequisites simply because they selected a school. Every pathway starts with the foundations required by that discipline, teaches them in context, then connects them to increasingly realistic work.

## 1. Programming and software development

**Prerequisites:** computer and file literacy, using a keyboard/editor, files and folders, basic arithmetic, binary intuition, command-line orientation and safe software installation.

**Progression:** inputs/outputs → algorithms and pseudocode → variables and types → operators → conditions → loops → functions → collections → files/errors → debugging/testing → data structures/complexity → OOP/design → Git → APIs/databases → security/deployment/maintenance.

**Evidence:** explain and trace a program, solve unseen tasks, write tests, review code and maintain a documented application.

## 2. Web, app and UI/UX

**Prerequisites:** browser/URL/file basics, visual hierarchy, reading/writing clarity, basic computer use and an understanding that users have goals and constraints.

**Progression:** internet/browser/request-response foundations → semantic HTML → CSS/cascade/box model → responsive layout → JavaScript/DOM/events → accessibility → UX research → information architecture → wireframes/prototypes → usability testing → design systems → APIs/data → performance/security/deployment.

**Evidence:** research-backed case study, accessible responsive implementation, prototype, usability findings and handoff documentation.

## 3. AI, data science and automation

**Prerequisites:** computer/file literacy, tables and data types, arithmetic, ratios, graphs, algebra, basic probability, Python orientation and ethical data handling.

**Progression:** data literacy → descriptive statistics → probability/sampling → Python → SQL → data cleaning → visualisation/storytelling → linear algebra/calculus concepts where needed → ML workflow → validation/metrics → neural-network concepts → LLM/token/context/embeddings → retrieval/tool use → evaluation, privacy, bias, monitoring and deployment.

**Evidence:** reproducible analysis, baseline comparisons, held-out evaluation, error analysis, documented limitations and safe automation.

## 4. Electrical, electronics and VLSI engineering

**Prerequisites:** arithmetic, fractions, ratios, algebra, scientific notation, rearranging equations, graphs, geometry/trigonometry, SI units, unit prefixes, dimensional analysis and foundational physics (charge, energy, force, fields and waves).

**Progression:** engineering measurement and lab safety → charge/current/voltage/power → resistance and Ohm's law → series/parallel circuits → KCL/KVL → network theorems and RC/RL transients → passive/active components → semiconductor physics and PN junctions → BJT/MOSFET → analog biasing/amplifiers/op-amps → binary/Boolean logic → combinational circuits → latches/flip-flops/FSMs/timing → C programming and computer architecture → microcontrollers/GPIO/ADC/PWM/serial buses → Verilog/SystemVerilog → simulation/testbenches/assertions → FPGA constraints/synthesis/timing → CMOS/VLSI power-area-performance and verification.

**Evidence:** calculations with units and assumptions, circuit simulations, safe measured lab work, firmware, self-checking HDL testbenches, synthesis/timing reports and a technical project defence.

**Field boundaries:** this pathway is electrical/electronics/VLSI. Mechanical, civil, chemical, biomedical and other engineering disciplines require their own prerequisite maps and dedicated courses; they must not be represented as covered by this course.

## 5. Office, documents and productivity

**Prerequisites:** keyboard/mouse, files/folders, file types, saving/exporting, cloud/local distinction, basic arithmetic and data-entry accuracy.

**Progression:** document structure and formatting → spreadsheet cells/references/formulas → functions/validation → data cleaning → charts/PivotTables/Power Query → presentation storytelling → collaboration/email/calendar → relational data/Access → data models/DAX/Power BI → automation, permissions and audit trails.

**Evidence:** accessible report, reconciled spreadsheet model, clear presentation, refreshable dashboard and documented workflow with error handling.

## 6. Personal finance and economics

**Prerequisites:** arithmetic, fractions, percentages, ratios, time periods, tables/graphs, income/expense vocabulary and distinguishing facts from assumptions.

**Progression:** money and cash flow → budgeting → banking/payment safety → simple/compound interest → inflation/time value → credit/debt/EMI → insurance and tax literacy with jurisdiction/date context → risk/return/diversification → asset classes and fees → financial statements → macroeconomic indicators/global markets → source checking and fraud awareness.

**Evidence:** fictional household budget, loan comparison, financial statement analysis and research memo that states risks and unknowns. Do not promise returns or provide personalised trading instructions.

## 7. Business, accounting and management

**Prerequisites:** arithmetic, percentages, tables, clear written communication, basic spreadsheet use and the difference between revenue, costs, profit and cash.

**Progression:** customer/problem/value → business models → accounting equation → double entry → journals/ledgers/trial balance → financial statements → budgeting/forecasting → unit economics/break-even → market research → marketing/sales → operations/process quality → project/people management → governance, ethics and strategy.

**Evidence:** balanced bookkeeping, reconciled statements, scenario forecast, market evidence, process map and decision-ready business case.

## 8. IT, networking, cloud and cybersecurity

**Prerequisites:** computer hardware/software, OS/filesystems, users/permissions, binary/decimal/hexadecimal, command-line basics and safe lab behaviour.

**Progression:** hardware/OS → files/processes/permissions → Linux/CLI → binary and IP addressing → Ethernet/TCP/IP → subnetting/CIDR → DNS/DHCP/NAT/routing → HTTP/TLS → virtualisation/containers → cloud/shared responsibility → identity/MFA/least privilege → defensive security → logs/monitoring/incident response → backups/recovery/DevOps.

**Evidence:** subnet plan, troubleshooting record, secure architecture, hardening checklist and incident runbook in an authorised lab only.

## 9. Career and professional skills

**Prerequisites:** self-assessment, basic writing, file management, truthful record of education/projects and awareness of role requirements.

**Progression:** role/job-description literacy → skills-gap mapping → communication → evidence-based CV → portfolio/Git hygiene → applications → behavioural interview frameworks → technical problem solving → presentations/group work → workplace conduct, privacy and job-search safety.

**Evidence:** tailored truthful CV, project case studies, mock interview review and role-specific development plan.

## 10. Creative and digital media

**Prerequisites:** computer/file literacy, visual observation, audience/message basics, image/file formats and copyright/consent awareness.

**Progression:** visual principles → composition/hierarchy → typography/colour → raster/vector and resolution → branding systems → image editing → audio/video fundamentals → storyboarding/editing → motion/keyframes → publishing formats/captions → analytics → licensing, attribution and portfolio.

**Evidence:** coherent identity system, accessible captioned media, asset credits and an evidence-based campaign case study.

## 11. Personal productivity and knowledge

**Prerequisites:** goal clarity, calendar/time awareness, basic written notes and understanding that workload and energy are limited.

**Progression:** outcomes and constraints → task decomposition → prioritisation → calendar/time estimates → focus/habit design → capture/organise/retrieve notes → active recall/spaced practice → decision journals/reviews → lightweight automation and sustainable operating systems.

**Evidence:** realistic weekly plan, retrieval-practice record, project workflow and retrospective.

## 12. Mathematics, science and research

**Prerequisites:** number sense, place value, arithmetic operations, fractions, decimals, percentages, ratios, units and reading simple tables/graphs.

**Progression:** arithmetic → algebra/equations → functions/graphs → geometry/trigonometry/vectors → limits/calculus → probability/statistics → physics/chemistry foundations → measurement/uncertainty → scientific method → literature search/source quality → reproducibility/ethics → technical writing and citation.

**Evidence:** step-by-step derivations, correctly unit-labelled calculations, uncertainty-aware data analysis and reproducible research report.

## Course authoring and release rule

A fundamentals map is a prerequisite checklist, not a completed course. For each course, author the actual lessons and worked examples, provide guided and independent exercises with explanations, add cumulative and final assessments, and require beginner/intermediate/advanced projects with rubrics. Add professional tools and standards only after the learner has the prerequisite concepts. Test the published page, not only the source file. Do not mark a school or course complete merely because this map exists.
