SkillSpring stores learning progress in this browser. Export a backup file on one device and import it on another. No account or cloud storage is involved.

Before importing: importing replaces matching SkillSpring progress keys on this browser with the values in your backup. Export your current progress first if you want to keep it. The backup may contain your practice code and learning state; store it privately and do not upload it to a public repository.

Privacy and limitations

  • The file is generated and read locally in your browser; SkillSpring does not upload it.
  • Only keys beginning with approved SkillSpring/Runcode prefixes are included.
  • Import is a manual transfer, not live synchronisation. There are no learner accounts or cloud profiles.
  • Different browser versions or changed course identifiers may not understand older progress values.
  • Never include passwords, API keys, financial account information or other secrets in practice data.
