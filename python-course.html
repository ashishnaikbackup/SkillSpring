YOUR GRADUATION PROJECT

Build a Personal Expense Tracker

Bring together input, variables, conditions, loops, functions, collections, file handling, error handling and tests. Build it in stages, then extend it into a command-line application that stores and summarises expenses.

  1. Ask the user to add an expense: amount, category, date and note.
  2. Validate input and handle invalid amounts safely.
  3. Store expenses in a list of dictionaries.
  4. Write and read records using a CSV or JSON file.
  5. Create functions for adding, listing, searching and summarising expenses.
  6. Calculate total spending and category totals.
  7. Add tests for important functions and document how to run the app.

Stretch goals: add SQLite storage, monthly reports, charts, a graphical interface or a web API. Never put real banking credentials or sensitive financial data in a learning project.
