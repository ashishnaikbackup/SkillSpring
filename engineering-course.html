Lessons

Project ladder · build evidence at every level

BEGINNER PROJECT

Resistor and LED design note

Calculate current-limiting resistance and power for a low-voltage LED circuit. Draw the schematic, state assumptions, simulate the circuit, compare expected and measured values in a supervised low-voltage lab, and explain tolerances.

Deliverables: calculations with units, schematic, simulation, measurement table, safety note and short explanation.

INTERMEDIATE PROJECT

Embedded sensor monitor

Read a sensor using a microcontroller ADC, filter or average samples, apply a threshold, control an LED with PWM and report readings over a serial interface. Include disconnected-sensor handling and a repeatable test plan.

Deliverables: block diagram, source code, pin map, test cases, logs, calibration note and demo.

ADVANCED CAPSTONE

Verified FPGA controller

Design a resettable finite-state machine and counter in Verilog/SystemVerilog. Build a self-checking testbench, cover reset and boundary cases, synthesise the design, constrain the clock, inspect timing and document trade-offs.

Deliverables: specification, RTL, testbench, assertions or checks, waveforms, synthesis/timing report, constraints and technical defence.

Shared project rubric (100 points)

  • Correctness and requirement coverage — 25
  • Engineering reasoning, calculations and assumptions — 20
  • Testing, verification and evidence quality — 20
  • Safety, component limits and responsible practice — 15
  • Documentation, reproducibility and version control — 10
  • Clear explanation and project defence — 10

Projects are portfolio exercises. Real hardware work must use suitable low-voltage equipment and supervision. Never use mains or high-voltage circuits as a beginner project.

Free and accessible engineering tools

  • CircuitJS/Falstad — interactive circuit exploration and transient intuition.
  • KiCad — open-source schematic capture and PCB design.
  • Icarus Verilog and GTKWave — HDL simulation and waveform inspection.
  • Yosys — open-source synthesis; FPGA implementation support depends on the target flow.
  • Arduino IDE — microcontroller programming environment.

Tool availability and device support can change. Check each project's official installation and licence information before use.

Professional engineering habits

Always state assumptions, show equations and units, check component and instrument ratings, use datasheets, document test conditions and distinguish simulation from measured hardware evidence. Never work on mains or high-voltage circuits without formal training and supervision. This course is a foundation, not an accredited qualification or substitute for laboratory instruction.
